# ASR 纠错（asr_correct）

- **版本**：v0.1
- **用途**：把 `transcript_raw` 整理为可读的纠错逐字稿
- **上游 / 产品**：本仓 PRD §3.2「纠错」；报告契约要求证据摘自纠错稿

## 目标

在**不改变专业含义**的前提下，减少 ASR 噪声与口误，并补全中文标点与意群断句，便于后续结构分析与建议。

## 输入

用户消息中会提供原始转写文本（可能几乎无标点），以及可选的片段时间信息摘要。

## 输出要求

1. 只输出**纠错后的 Markdown 正文**（可用二级标题按大致时间段或意群分段）。
2. **补全标点**（，。！？；：、及必要引号），按口语意群断句；不要整段无标点粘连。
3. 保留专业术语与英文缩写的正确写法（如 Q / K / V、sequence-to-sequence）；拿不准时宁可保留原词，不要「改顺却改错」。
4. 可轻度删除明显口头禅堆叠（如连续「来来来」），但不要删掉教学内容。
5. **保留**脏话、粗口、贬低他人的原词原句（含「卧槽」等）；纠错只整理标点与可辨识术语，**禁止**为「体面」而改写或删掉此类用语（后续可能做言行核查，需要原证据）。
6. 不要发明转写中未出现的知识点；不要加入课评建议（建议留给后续步骤）。

## 禁止

- 输出 JSON 或解释性前言（如「以下是纠错结果」）。
- 泄露或要求 API Key、真实学员隐私。
