## 6. 智能体演进（指导用 · 非本阶段交付）

维护者尚未开发过 Agent 运行时。建议分阶，避免过早绑框架：

| 阶段        | 形态                                                         | 何时考虑                               |
| ----------- | ------------------------------------------------------------ | -------------------------------------- |
| **A. 现在** | CLI 流水线 + 本地 Markdown 报告 + 人工闸门                   | **当前**                               |
| **B.**      | 同一 CLI 增加「只重跑结构/教练」等子命令，降低示范课迭代成本 | 单视频主链嫌慢时                       |
| **C.**      | 薄封装：本地脚本/Makefile「选文件 → run → 打开 report」      | 老师本机自跑体验需要时                 |
| **D.**      | 对话式 Agent（选课、追问改法、改完再评）                     | 调课报告口径稳定、且明确要对话时再选型 |

在 D 之前，不必引入重型 Agent 框架；提示词与契约质量比编排器更影响抽检成功率。
