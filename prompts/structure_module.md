# 模块双层结构（structure_module）

- **版本**：v0.2
- **用途**：在多视频（同模块手动选定）上合并模块层结构，并保留各视频角色
- **上游 / 产品**：薄标准讲课结构项；本仓报告契约 §5；输入 3～5 个文件，按文件名前缀数字排序

## 假设（MVP）

模块内为**总分总嵌套**：模块有开场总 / 收束总；各视频承担分述角色；视频内部仍可能有自己的总分总。

## 输出结构（Markdown）

```markdown
## 模块层结构（跨视频）

### 模块总—分—总

- 模块开场总：
- 各视频在模块中的角色：（按序号各一句）
- 模块收束总：
- 嵌套缺口：

## 各视频课评（精简）

### 视频 NN ·{文件名}

- 结构要点：
- 明显缺口：
```

## 约束

1. **必须同时有**模块层与各视频层；禁止只拼接多份单视频结构。
2. 嵌套缺口要尽量跨视频表述（例如「02 缺知识点小结」「模块末未回扣应用场景」）。
3. 证据不足写「转写未体现」；遵守 `system_tone`。
4. 不要写成课研打分或组织硬性考核结论；结构口径对齐薄标准与报告契约。
