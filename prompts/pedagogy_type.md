# 旁路细课型判定（pedagogy_type）

- **版本**：v0.1
- **用途**：根据纠错逐字稿与标题，判定上游备课方法专文 `004`～`010` 之一；无法把握时标 `other`
- **范围**：仅 `batch-conduct` 旁路日分布；**不是**主路径 `lesson_type`（principle/code/lab）门禁
- **上游**：备课方法 `004`～`010`（阶段第一课 / 简介 / 实操 / 代码语法 / 案例 / 原理 / 项目）

## 判定原则

1. 只选**一个**主类型；混合课时选占比最大、最能概括本段目的的一类。
2. 没有把握 → `other`（宁可 other，不要硬猜）。
3. 文件名 / `title_anchor` 仅作线索，以正文实际讲法为准。
4. 「吹牛、闲聊、拖堂开场」若主体是阶段导入 / 动员 / 自我介绍 → 倾向 `004`；若主体是项目背景与架构 → 倾向 `010`；纯机制推导 → `009`。
5. 共屏跟敲安装配置 → `006`；逐行讲语法 / API → `007`；带业务故事的综合案例 → `008`。

## 输出（仅 JSON）

```json
{
  "pedagogy_type": "004",
  "confidence": "high",
  "rationale": "一句话说明为何是该类型（勿评价人）"
}
```

- `pedagogy_type`：`004` \| `005` \| `006` \| `007` \| `008` \| `009` \| `010` \| `other`
- `confidence`：`high` \| `medium` \| `low`（low 时实现侧会降为 `other`）
- 不要输出 Markdown；不要输出合格线结论。
