# ADR-0004：专业知识预审两段式（Pass A / Pass B）与假阳性闸门

- **Status**：Accepted
- **Date**：2026-07-25

## Context

单视频竖切已能产出 `report.md`，但维护者最关心：

1. 知识是否讲准；
2. 案例是否恰当；
3. 小闭环与递进、总分总；
4. 完整教学能力摘要与「最急需 Top 3」（权重见报告契约；v0.3 起含讲清度，见 ADR-0005）。

若把「专业对错」与结构/建议捆在同一轮 LLM 调用里，模型容易用百科知识「脑补」讲义标准，造成**假阳性**（错杀），损害生产可用性。维护者确认：先以**视频标题**为知识锚点做专业预审，再在预审结果上做综合报告；**宁可漏报，不可错杀**。

## Options considered

| 选项                               | 优点                     | 缺点                                   |
| ---------------------------------- | ------------------------ | -------------------------------------- |
| 单轮 coach 包办专业+结构+Top3      | 调用少、实现快           | 假阳性难控；专业结论与结构结论缠在一起 |
| Pass A 专业预审 JSON → Pass B 综合 | 闸门清晰；可审计；可复现 | 多一次 LLM 调用；标题弱时须更保守      |
| 外挂讲义/题库做判分                | 更接近「标准答案」       | MVP 无讲义输入；范围膨胀；本阶段不做   |

## Decision

1. **两段式 LLM**：
   - **Pass A（专业预审）**：输入 = 纠错逐字稿 + 视频标题（及文件名作辅）；输出 = **`knowledge_review.json`**（机器可读）。
   - **Pass B（综合）**：输入 = 纠错稿 + Pass A JSON + 结构分析；输出结构要点、六维摘要、Top3 与 `report.md`。
2. **标题角色**：只作「本课主题锚点」，**不是**标准答案全文。
3. **漏讲**：标题暗示但转写未出现的内容，默认 **`unverified`（待核实）**，**不进入合格线 / Top3 必改**。
4. **假阳性闸门**（硬约束，实现与提示词必须遵守）：
   - 无纠错稿摘句（鼓励带时间）→ 不得判 `issue`；
   - `issue` 且 `confidence=high` 才可进合格线 / Top3；
   - `unverified` / `low` 仅可进「待核实」或水平线旁注；
   - Pass B **不得新造**无 Pass A 证据支撑的「知识错误」指控。
5. **本阶段不做**：讲义对照库、1–5 分雷达考核、教学六力听课表强绑。

## Consequences

### 正面

- 专业结论可单独回归、可人工抽检 JSON；
- 生产上优先控制错杀，符合「教练不是监工」；
- 与上游授课力 **V1（专业力）** 可观察部分对齐，且不冒充硬性制度。

### 负面

- 全量 `run` 增加至少一次 LLM 调用与耗时/费用；
- 标题含糊（如仅 `day01`）时，Pass A 必须声明锚点弱并更保守；
- 仍可能**漏报**真实知识错误与「讲了但没讲清」（可接受；讲清度补强见 ADR-0005，讲义输入仍非本阶段）。
