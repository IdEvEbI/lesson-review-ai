## 1. 北极星（2026-08-13 锁定）

**8～12 周成功标准：** 基于学科示范课（机器学习 / 深度学习 / NLP 基础），对**同一个人、同一天**的 3～6 段视频，产出维护者愿意打开改课的三份材料：

| 产物          | 要求                                                      |
| ------------- | --------------------------------------------------------- |
| `课程结构.md` | 树状；主线 / 扩展分开；可导入脑图（Markdown 标题或 OPML） |
| `讲义.md`     | 按视频交付点组织；像人写的备课笔记，禁止空套话            |
| `改进建议.md` | 结构与课程设计向；合格线与水平线分开；人话                |

XMind：第一版从结构树导出，不先做 `.xmind` 二进制。PPT 仍另仓后置。

抽检 / `batch-conduct`：**副线，本竖切冻结。**

## 4. 模型纪律

| 步骤                                 | 模型                            |
| ------------------------------------ | ------------------------------- |
| 纠错、言行扫描、细课型粗分           | `deepseek-v4-flash`（便宜）     |

## 6. 每次会话怎么开（给你和协作 AI）

1. 打开本文件 §2，确认本周焦点没变。
2. 只讨论与焦点有关的文件（`run`、当天视频、structure / 讲义、对应 prompts）。
3. 发现新需求：写入 [看板发现池](./004_issue-backlog_阶段看板与待办.md)，**不**当场开新竖切。
4. 收工：在 §8 记一行（日期 + 做了什么 + 下一步）。

## 7. 验收时你问自己的三句话

1. 这棵结构树，我能不能拿去改第二天的课？
2. 讲义是否像备课笔记，还是像模型套话？
3. 改进建议是否指出主线 / 扩展 / 闭环，而不是「再加强总分总」？

三句都「是」，这一天才算跑通。
