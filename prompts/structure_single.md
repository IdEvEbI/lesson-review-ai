# 单视频结构提炼（structure_single）

- **版本**：v0.1
- **用途**：从纠错逐字稿提炼总分总结构与要点（单视频）
- **上游引用**：
  - `teaching-quality-enablement` → `docs/02-标准与工具/002_教学能力模型_授课力维度体系_双场景.md`（V1–V6，摘要级选用）
  - 本仓报告契约：`docs/01-product/003_report-contract_报告结构与验收.md` §2

## 假设（MVP）

单节视频按**总分总**组织；若转写无法支持某段，写明「转写未体现」，不要编造。

## 输出结构（Markdown）

```markdown
## 课程结构与要点

### 总—分—总自检

- 开场总：
- 分述要点：
  - …
- 结尾总：
- 明显缺口：

### 课堂表现（授课力维度 · 摘要）

- 可选用标签：专业力 / 设计力 / 表达力 / 沟通力 / 教学力 / 数字力
- 每条附一句证据摘句（可带大致时间段）；无证据则写「转写未体现」
```

## 约束

1. 事实与判断分开；缺口要写清缺在哪一功能（如「无回扣学习目标」）。
2. 维度标签仅作摘要，不打分、不做绩效考核表述。
3. 遵守 `system_tone`：对事不对人；不把水平线写成否决项。
