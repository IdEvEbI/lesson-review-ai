## 1. Background

### 1.1 两案投诉核查后的产品判断（2026-08）

维护者完成吴老师（大模型）、黄老师（智能应用）两日课投诉核查后，确认：

1. **授课节奏**：常偏离 A01（开场 / 收尾 / 作业闭环）。
2. **单视频结构**：硬套总分总外壳，**主线不清晰**，小交付点多且缺少逻辑递进——大模型学科尤为突出（课程设计能力偏弱）。
3. **讲练与粘贴**：粘贴代码偏多、手敲与业务原因偏少；原理占比与可验证交付易失衡。
4. **模型能力**：现用成本优先模型易夸大完成度、误判细课型 / 主交付；**通读纠错稿再核 summary / 结构 / 教练结论** 必须成为闸门，不能跳过。

`batch-conduct`（E4b）已能支撑日分布与言行旁路，但**不能**替代单视频课评教练。下一竖切应回到主路径：把单个视频的结构检查与教练报告做到「维护者愿意用、带教能拿去带新人」。

### 1.2 赋能顺序（本竖切锁定）

```text
维护者验收单视频教练报告
  → 分校带教老师优先内测（先提升自身课程设计与教学能力）
  → 带教用同一套口径带新老师
  → 暂不开放全体老师自查门户
```

- **第一读者（报告）**：维护者 → 验证通过后的**分校带教**。
- **第二读者（间接）**：新老师（由带教控制场合与裁剪，遵守三不三要）。
- **不做**：公开考核、羞辱性传阅、越级指挥一线。

## 2. Goal

在脱敏样例上，单视频流水线稳定产出：

1. **课程设计向**的结构判断：是否硬套总分总、主线是否清晰、交付点是否过多且无逻辑、本段**唯一（或主）交付**是什么；
2. **可执行改法**：合格线 / 水平线分开；带方法，不公开点名；
3. **证据边界**：转写可证 vs 待回放；无摘句不得抬合格线；
4. **人工闸门**：纠错稿通读 → 修正记录 → 方可把报告视为可外发带教的依据。

验收通过后，维护者可启动**分校带教优先内测**（须同步更新 PRD §2.1）。
