## 4. Issue 写法规范（企业常见实践）

每个 GitHub Issue 建议包含：

1. **背景**：链到 PRD 章节或 ADR。
2. **范围**：本 Issue 做 / 不做（防止 scope creep）。
3. **验收标准**：可勾选列表（验收方式为由维护者在本机试用并勾选清单）。
4. **依赖**：Blocked by #n。
5. **类型标签**：`feat` / `docs` / `chore` / `test`。
6. **竖切标注**：是否属于 M1 演示路径。

PR 描述应链接 Issue，并附「样例运行命令 + 报告截图或路径说明」（无真实学员信息）。
