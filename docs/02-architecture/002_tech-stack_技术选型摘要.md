# 技术选型摘要

- **版本**：v0.1.1
- **日期**：2026-08-06
- **状态**：已采纳默认（详见 `adr/`）

本文是**一页纸选型结论**；论证过程见各 ADR。

---

## 1. 总览

| 层次   | 选择                                                          | 备注                                                                  |
| ------ | ------------------------------------------------------------- | --------------------------------------------------------------------- |
| 语言   | **Python 3.11+**                                              | 维护者已熟悉 Python 技术栈；ASR / LLM 生态成熟                        |
| 包管理 | **uv** 或 **pip + venv**（实现 Issue 中二选一并写入项目约定） | 倾向 uv，锁依赖可复现                                                 |
| 编排   | **CLI 单体**                                                  | 无微服务、无队列（MVP）                                               |
| 抽轨   | **ffmpeg**（Homebrew）                                        | 业界标准                                                              |
| ASR    | **mlx-whisper**，默认 `large-v3-turbo`                        | 在 Apple M5、24GB 内存上本地运行，利于隐私保护，且不产生 ASR API 费用 |
| LLM    | **DeepSeek API**（OpenAI 兼容）                               | 性价比与中文表现；Flash 默认，Pro 可升档                              |
| 提示词 | **`prompts/*.md`**，与 git 版本绑定                           | GenAI 场景按代码同等对待（版本化）                                    |
| 产物   | **Markdown + JSON manifest**                                  | 人读 + 机读                                                           |

C++ / whisper.cpp：不作为 MVP 主路径；若 mlx 不可用再开 ADR 讨论回退。

## 3. LLM 使用策略

| 步骤     | 模型建议          | 说明                                                          |
| -------- | ----------------- | ------------------------------------------------------------- |
| 纠错     | DeepSeek V4 Flash | 长文本、多次迭代成本低                                        |
| 结构提炼 | Flash             | 可先试 Flash；若产出的结构仍混乱，再改用 Pro 模型             |
| 教练建议 | Flash → Pro       | 若教练建议过于空泛，可仅升级该步骤，或整条流水线改用 Pro 模型 |

**备选**：通义千问 DashScope（企业开票 / 合规）；通过 `LLM_BASE_URL` 与 `LLM_API_KEY` 切换，不在代码中写死单一厂商。

**不建议 MVP 默认**：OpenAI / Claude 作为日常路径（成本高；可作抽样对照）。

---

## 4. 可复现与 MLOps 轻量实践

采纳企业 MLOps 共识中的**最小子集**（不引入 MLflow 等重型平台）：

1. **每次 run 写 manifest**：输入哈希、ASR 模型 id、LLM 模型、prompt 文件 git 短 hash。
2. **提示词变更 = 代码变更**：走 PR，附同一课例前后报告对比说明。
3. **固定回归课例**：维护者提供的脱敏样例，不进库；路径写入本地 `data/README`（可选）或仅私人笔记。
4. **后续 CI**：`ruff` + 契约测试 + `lesson-review run --dry-run`（Issue 单列）。

## 5. 安全

- 密钥仅 `.env`；`.env.example` 只列变量名。
- 日志禁止打印 Key 与完整逐字稿（调试开关单独 Issue）。
- 报告对外分享前由维护者脱敏。
