## 1. 原则

- **业务口径以上游为准**；本仓提示词是执行层，不是立法层。
- 引用时写明上游相对路径与文档版本（文首版本号），便于回溯。
- 上游草案仍可摘要进本仓契约，但须标注上游版本；冲突时以上游最新正文为准，并回改本仓摘要与 `prompts/`。
- **不要**把课研打分表升格为日常课评 Pass A/B 的第一门禁。
- 本仓为 public 仓库：上游文中若有维护者真名或品牌名，**不要抄进**本仓文档与提交说明。

## 3. 提示词落盘建议

```text
prompts/
  system_tone.md          # 三不三要、合格线水平线、文风（对齐薄标准语气）
  asr_correct.md          # 纠错
  knowledge_cases.md      # Pass A：准确性 / 讲清度 / 案例 / coverage_gap
  structure_single.md     # 单视频结构（首选薄标准讲课检查项）
  structure_module.md     # 模块嵌套结构
  teaching_outline.md     # 讲解重点提纲（回避 Pass A issue；含课型；lab 见契约 §10）
  coach_feedback.md       # Pass B：综合建议、Top3、待回放确认（消费 Pass A）
  conduct_scan.md         # 旁路：高风险话术筛查（对齐 A07 / 薄标准 §5）
```

变更评价维度时：先改上游或确认上游已有表述 → 更新本仓报告契约 / ADR → 再改对应 `prompts/` → 用同一课例回归对比报告差异。专业预审两段式见 [ADR-0004](./adr/0004_two-pass-knowledge-review.md)；讲清度与待回放见 [ADR-0005](./adr/0005_clarity-and-playback-boundary.md)；实操课三条见 [ADR-0006](./adr/0006_lab-pedagogy-checks.md)（**Accepted**）。
