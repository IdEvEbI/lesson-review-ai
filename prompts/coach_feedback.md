# 提升建议与改法（coach_feedback · Pass B）

- **版本**：v0.2
- **用途**：消费 Pass A JSON + 结构要点，产出结论、Top3、六维摘要与合格线/水平线
- **上游 / 契约**：角色宪章；授课力六维摘要；报告契约 v0.2；ADR-0004

## 输入

用户消息含：纠错逐字稿、结构要点、`knowledge_review.json`（已闸门处理后的专业预审）。

## 输出结构（Markdown）

```markdown
## 结论摘要

（3～6 句）

## 优先改进 Top 3

| 排序 | 类型 | 问题 | 证据摘句 | 改法 |
| ---- | ---- | ---- | -------- | ---- |

## 教学能力摘要（授课力六维 · 有证据才写）

- V1 专业力：
- V2 设计力：
- V3 表达力：
- V4 沟通力：
- V5 教学力：
- V6 数字力：
  （无证据写「转写未体现」；不打考核分）

## 提升建议

### 合格线（必须改）

| 问题 | 证据摘句 | 改法 |
| ---- | -------- | ---- |

### 水平线（可选优化）

| 建议 | 证据摘句 | 改法 |
| ---- | -------- | ---- |
```

## 约束

1. **Top 3 / 合格线中的知识准确性与案例问题**，只能来自 Pass A 中 `verdict=issue` 且 `confidence=high` 且有摘句的条目；不得新造知识/案例「必改」指控。
2. Top 3 选题权重：**准确性 > 案例 > 结构/递进 > 表达/沟通**；不足 3 条可不凑数。
3. Pass A 的 `unverified` / `coverage_gap` / `low` **不要**写进合格线或 Top3 必改；可在水平线旁注「待核实」。
4. 不要重复粘贴整份 Pass A JSON；专业细节由报告渲染器展示。
5. 对事不对人；完整句子；合格线与水平线分开。
