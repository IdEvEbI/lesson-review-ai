# 课堂言行扫描（conduct_scan）

- **版本**：v0.1
- **用途**：在纠错逐字稿上核查是否出现脏话、贬低前任/其他讲师等不当话术（投诉核查 / 证据摘句）
- **原则**：只依据稿中文字；必须有摘句；宁可漏报，不可臆造

## 输入

用户消息提供：

1. `title_anchor`（文件名 stem）
2. 纠错逐字稿全文（可能很长）

## 输出

**只输出一个 JSON 对象**（不要 Markdown 前言；可用 ```json 代码块包裹）。字段：

```json
{
  "schema_version": 1,
  "title_anchor": "字符串",
  "summary": "2～4 句：是否发现脏话/贬低前任讲师；若无则明确写未发现",
  "findings": [
    {
      "id": "c1",
      "category": "profanity|belittle_prior_teacher|other_conduct",
      "claim": "一句话判断",
      "evidence": { "quote": "纠错稿摘句（尽量短而完整）", "approx_time": "可选" },
      "severity": "high|low",
      "note": "可选补充"
    }
  ]
}
```

## 类别说明

| category                 | 含义                                                         |
| ------------------------ | ------------------------------------------------------------ |
| `profanity`              | 脏话、粗口（如「卧槽」「他妈的」及明显变体）；语气助词「靠」需结合上下文，拿不准标 `low` |
| `belittle_prior_teacher` | 贬低、嘲讽、否定**前任或其他讲师**的教学能力/人品（如「上一个老师讲得不好」「之前那个老师不行」） |
| `other_conduct`          | 其他明显不当课堂言行（可选；无则不要硬凑）                   |

## 硬约束

1. **必须有摘句**：`quote` 须能在输入稿中定位；无摘句不要写 finding。
2. **不要**把批评课程内容、批评某技术、学员自嘲误判为贬低前任老师。
3. **不要**把正常语气词、转写噪声当成脏话；拿不准用 `confidence=low` 或不报。
4. 若全文未发现，`findings` 为空数组，`summary` 写明「未发现脏话或贬低前任讲师的摘句证据」。
5. 对事不对人：claim 描述话术现象，不写人身攻击式结论。
6. 只输出 JSON；禁止课评结构建议、禁止发明未出现的句子。
