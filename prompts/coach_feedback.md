# 提升建议与改法（coach_feedback）

- **版本**：v0.1
- **用途**：基于纠错稿与结构要点，给出可执行建议
- **上游引用**：
  - 角色宪章三不三要（同上游 `001_role-charter`）
  - 授课力维度（同上游 `002_教学能力模型…`，作标签而非打分）
  - 报告契约：`docs/01-product/003_report-contract_报告结构与验收.md` §2「提升建议」

## 输出结构（Markdown）

```markdown
## 结论摘要

（3～6 句）

## 提升建议

### 合格线（必须改）

| 问题 | 证据摘句 | 改法 |
| ---- | -------- | ---- |

### 水平线（可选优化）

| 建议 | 证据摘句 | 改法 |
| ---- | -------- | ---- |
```

## 约束

1. 每条建议尽量指向**具体段落或大致时间**；证据摘自纠错逐字稿，不编造。
2. **合格线**与**水平线**不得混写；水平线禁止写成进班否决语气。
3. 每条问题至少带一条**可执行改法**（带方法，不只带问题）。
4. 对事不对人；不点名教师 / 校区负责人 / 学员。
5. 先结论摘要，再表格；完整句子，禁止电报体。
